# Классификация изображений кошек с помощью ConvNeXt Tiny

Курсовой проект по компьютерному зрению: нейронная сеть определяет категорию кошки по фотографии, выбирая один из **15 классов**. Работа выполнена в **PyTorch** с использованием предобученной модели **ConvNeXt Tiny**, аугментаций изображений и переноса обучения (transfer learning).

**Основной результат:** после пяти эпох обучения классификатора и трёх дополнительных эпох с уменьшенным learning rate точность на валидационной выборке составила **76,66%**. Помимо обучения, проект включает анализ ошибок, визуализацию Grad-CAM и просмотр карт признаков на разных уровнях сети.

Основной файл — [Гильманов Курсовой проект.ipynb](Гильманов%20Курсовой%20проект.ipynb). Ноутбук содержит код и сохранённые результаты экспериментов и ориентирован на запуск в Google Colab.

## Цель проекта

Применить предобученную нейронную сеть к задаче классификации изображений кошек, оценить качество на выделенных выборках и визуально исследовать признаки, которые модель использует при предсказании.

**Классы датасета:** Abyssinian, American Bobtail, American Shorthair, Bengal, Birman, Bombay, British Shorthair, Egyptian Mau, Maine Coon, Persian, Ragdoll, Russian Blue, Siamese, Sphynx и Tuxedo.

Названия приведены в соответствии с разметкой датасета. Ссылка на источник и условия использования набора данных в ноутбуке не указаны; для повторного запуска потребуется отдельно получить исходный архив.

## Подготовка изображений

Все изображения приводятся к размеру **224 × 224 пикселя** и преобразуются в тензоры. Для обучающей выборки дополнительно применяются:

- случайное горизонтальное отражение;
- случайный поворот в пределах 10°;
- изменение яркости и контраста (`ColorJitter`, параметры по 0,2).

На валидации и тесте случайные аугментации отключены. Данные передаются модели пакетами по **32 изображения**, обучающая выборка перемешивается.

## Архитектура и обучение

Используется **ConvNeXt Tiny** с весами `IMAGENET1K_V1`, предобученными на ImageNet. Последний линейный слой заменён на классификатор с 15 выходами.

Параметры основной сети заморожены: оптимизатор обновляет только последний линейный слой. Это позволяет использовать уже выученные визуальные признаки для новой задачи.

| Параметр | Значение |
|---|---|
| Модель | `torchvision.models.convnext_tiny` |
| Предобученные веса | `ConvNeXt_Tiny_Weights.IMAGENET1K_V1` |
| Число классов | 15 |
| Функция потерь | `CrossEntropyLoss` |
| Оптимизатор | Adam |
| Размер пакета | 32 |
| Первый этап | 5 эпох, `lr=0.001` |
| Второй этап | 3 эпохи, `lr=0.00001` |

В ноутбуке второй этап обозначен как fine-tuning, однако перед ним основная сеть не размораживается. Фактически это продолжение обучения последнего слоя с меньшей скоростью обучения. Градиенты для всех параметров включаются позже для построения Grad-CAM, после завершения обучения.

## Результаты

Ниже приведены метрики из сохранённых выводов ноутбука. Accuracy — доля изображений с правильно предсказанным классом.

| Этап | Train Loss | Train Accuracy | Validation Loss | Validation Accuracy |
|---|---:|---:|---:|---:|
| Завершение первого этапа, эпоха 5 | 0,8865 | 77,17% | 0,8052 | 75,36% |
| Второй этап, эпоха 1 | 0,8330 | 78,13% | 0,8023 | 75,47% |
| Второй этап, эпоха 2 | 0,8523 | 77,88% | 0,8001 | 76,18% |
| Второй этап, эпоха 3 | **0,8255** | **78,36%** | **0,7987** | **76,66%** |

Дополнительное обучение повысило валидационную точность на **1,30 процентного пункта** — с 75,36% до 76,66%. Одновременно валидационная функция потерь снизилась с 0,8052 до 0,7987.

На тестовой выборке из 844 изображений построены матрицы ошибок до и после второго этапа. **Общая тестовая Accuracy, Precision, Recall и F1-score отдельными числовыми результатами в ноутбуке не выведены.** Значение 76,66% относится именно к валидации.

## Визуализация и интерпретация

В работе представлены:

- **Примеры обучающих изображений** с названиями классов.
- **Кривые Loss и Accuracy** для обучения и валидации на первом этапе.
- **Матрицы ошибок** на тестовой выборке для анализа того, какие категории модель путает.
- **Пример предсказания** для случайного тестового изображения с истинной и предсказанной меткой.
- **Grad-CAM:** тепловая карта областей изображения, связанных с выбранным моделью классом.
- **Карты признаков:** до 16 каналов на раннем, промежуточном и глубоком уровнях ConvNeXt, полученных через `forward hooks`.

Эти визуализации помогают исследовать поведение сети и отдельные ошибки. Grad-CAM показывает чувствительные для предсказания области, но сам по себе не доказывает правильность решения.

## Ограничения и дальнейшее развитие

- **Предобработка:** в текущем коде нет нормализации по статистикам ImageNet. Следующий эксперимент — согласовать преобразования с требованиями предобученных весов и повторно оценить качество.
- **Обучение:** основная сеть остаётся замороженной. Можно проверить дообучение последних блоков ConvNeXt с небольшой скоростью обучения.
- **Воспроизводимость:** фиксируется разбиение выборок, но не все случайные процессы PyTorch, NumPy и Python. Версии библиотек также не зафиксированы, поэтому результаты повторного запуска могут отличаться.
- **Оценка качества:** полезно дополнить матрицу ошибок тестовыми Accuracy, macro-F1, Precision и Recall по каждому классу и анализом баланса классов.
- **Сравнение архитектур:** ResNet50 и EfficientNet-B0 присутствуют только в закомментированных вариантах кода. Подтверждённого сравнения их качества с ConvNeXt в этом ноутбуке нет.
- **Использование модели:** сохранение обученных весов и отдельный интерфейс для загрузки пользовательских фотографий пока не реализованы.
